# Employee Attendance Dashboard — HR Analytics

A real-time Power BI dashboard built to help HR teams move away from manual Excel-based attendance reporting and track employee attendance more efficiently.

## 📊 Overview

This project consolidates attendance data from Excel files and SQL databases into a single, interactive Power BI dashboard — enabling HR teams to monitor attendance, spot absenteeism trends, and generate insights throughout the month without manual report-building.

## 🎯 Objective

Build a real-time Power BI dashboard that automates attendance reporting for the HR team, replacing manual Excel-based tracking with an easy-to-use, interactive solution.

## 🗂️ Dataset

- **Sources:** Excel files + SQL database (employee attendance records)
- **Key fields:** Employee ID, Date, Attendance Status, Department (as applicable)
- **Data issues handled:** Data accuracy checks during cleaning and consolidation

## 🔧 Tools & Skills Used

- **Power BI** — dashboard design and visualization
- **SQL** — querying attendance data from the database
- **Excel** — supplementary data source
- **Data Cleaning** — ensuring accuracy across combined data sources

## 🖥️ Dashboard Features

- **Real-Time Attendance Tracking:** Live view of employee attendance status
- **Absenteeism Trend Analysis:** Visuals highlighting patterns over the month
- **Interactive, Easy-to-Read Layout:** Designed for HR users without a technical background
- **Automated Reporting:** Removes the need for manually rebuilding Excel reports each period

## 🔍 Key Business Insights

- Automated the reporting process, **saving significant manual effort** previously spent on Excel-based tracking.
- Improved visibility into attendance patterns, helping HR **identify absenteeism trends** early.
- Enabled HR to make **faster, better-informed decisions** through a clear, visual reporting format.

## 🚀 How to Use

1. Clone or download this repository.
2. Open the `.pbix` file in [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Explore attendance trends and absenteeism patterns using the dashboard's interactive visuals.
